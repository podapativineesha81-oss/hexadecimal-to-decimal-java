# 🔢 Hexadecimal to Decimal Java

## 📌 Project Overview

The **Hexadecimal to Decimal Java** is a simple Java-based application that converts a hexadecimal number into its decimal representation using positional values and powers of 16.

---

## 🚀 Features

- Accepts a hexadecimal number
- Validates hexadecimal digits
- Supports digits from 0 to 9 and A to F
- Converts hexadecimal to decimal
- Supports uppercase and lowercase hexadecimal input
- Simple console-based interface

---

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Concept:** Number System Conversion
- **Algorithm:** Positional Value Method
- **Input Handling:** Scanner
- **Version Control:** Git & GitHub
